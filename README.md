Midikeypad is an instrument with Sliders, rotary encoders, neopixels ,switches and capacitive touch with the form of a DJ set
My midi key pad is base on the design of the midikeypad of Kai Pereira only changes the order of the components and the shapes of the pads but i made it based on a DJ set because all the stuff that it uses remenber to me to DJ set
Components:
switches push
potentiometer
Neopixels
pads
rotatory encoder
Waveshare ESP32-S3-ZERO

this work by touching the pads ,this is because the pads have like an electric field and when you touch it your own electric field interferes with the one of the midikey
